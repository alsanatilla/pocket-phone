# Pocket 0.7.1

Open the [web workspace](https://alsanatilla.github.io/pocket-phone/) and choose **pip**. Its chat now has the approved pixel glow: fine rings behind the composer, a bloom in the top corner and a dark centre for reading. The same scene is included in the Android app. Movement and Gym remain separate tabs.

The release includes `pocket-phone-0.7.1-unsigned.apk` (version code 31), a web archive, a source archive, build status and checksums. The APK must be signed by the release agent before installation. Use the existing signing certificate to update an installed Pocket app while retaining local data.

The test suite is skipped as requested. The generated glow artwork was inspected at phone and desktop sizes; authenticated browser preview and physical handset rendering were unavailable for this build. Compilation results and the APK checksum are in `BUILD-STATUS.json`.
