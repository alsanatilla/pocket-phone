# Pocket 0.7.2

Open the [web workspace](https://alsanatilla.github.io/pocket-phone/). Pip keeps only the upper-corner pixel glow, fading into black.

In **Gym**, choose **+ exercise** to add another lift to the current workout. Tap an exercise in the workout list to return to its sets. The exercise picker also switches between lifts and offers **+ new exercise** for a custom name. Finish once the whole workout is complete. Phone and web retain each exercise's sets in the same workout record.

The release includes `pocket-phone-0.7.2-unsigned.apk` (version code 32), a web archive, a source archive, build status and checksums. The APK must be signed by the release agent before installation. Use the existing signing certificate to update an installed Pocket app while retaining local data.

The test suite is skipped as requested. Authenticated browser preview and physical handset rendering were unavailable for this build. Actual verification and the APK checksum are in `BUILD-STATUS.json`.
