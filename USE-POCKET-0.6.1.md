# Pocket 0.6.1

Open the [web workspace](https://alsanatilla.github.io/pocket-phone/). Home and Today now use a static dithered sky fading to black, inspired by your supplied reference. The phone and web use Pocket's palette and the same pixel pattern. The existing Thoughts, Tasks, Notes and Pip workflow is retained.

The GitHub release includes `pocket-phone-0.6.1-unsigned.apk` for the release agent to sign. Version name is `0.6.1`, version code `29`, package `org.textphone.launcher`, minimum Android version 7.0. Keep the current installation and its data; this artifact needs signing before installation. The APK is a native launcher/app build, not a flashable ROM.

Compilation results and checksums accompany the release. The test suite is skipped as requested. Handset animation, camera output and live account synchronization remain unverified.
