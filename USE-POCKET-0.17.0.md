# Pocket 0.17.0 — Warm Console

Home and Today now start with COROS stat bars, your next appointment and chosen or due tasks. Thoughts remain separate until you choose **make task**. The daily brief is available from Apps or an optional tile.

Use **+ add tile** and **edit tiles** on Today. On the phone, holding a tile also offers moving or removing it. The layout saves locally and syncs with your Pocket account.

Tasks opens at **All**. Complete a task from its checkbox; expand its steps to mark them individually. Notes saves as you type. Apps groups Pocket tools; the phone's **Installed** tab lists installed applications.

Pip's sprite opens chat. Expand activity to see actual tool inputs, search queries, status and sources. Provider reasoning is separate. Keeping a reply as a note, thought or task remains your choice.

Open **Apps → set up pocket** for account, phone linking, COROS and Pip. Use the same account on both devices. Pip keys stay on each device.

Downloads include the APK (version code 44), web and complete source archives, build status and checksums. The APK is **unsigned** for the signing agent. An update that retains local data needs the existing signing certificate.

Android and Astro production builds passed, with focused native and browser checks. Physical handset interaction and a real virtual keyboard remain unverified. Provider checks used simulated responses; existing broad-suite failures are recorded in BUILD-STATUS.json.
