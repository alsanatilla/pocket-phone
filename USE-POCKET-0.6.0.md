# Pocket 0.6.0

Open the [web workspace](https://alsanatilla.github.io/pocket-phone/). Today, Thoughts, Tasks and Notes share one workflow. Use optional Drive sync to share those records with the phone. Pip is available in the browser with the same Pocket design and animated character as the phone; configure its API key in API settings. Pip chats remain local to each device. Explicitly kept Notes, Thoughts and Tasks use the existing sync collections.

The GitHub release includes `pocket-phone-0.6.0-unsigned.apk` for the release agent to sign with Pocket's existing key. This file is not an installable update until signed. Keep the current installation and its data. Version name is `0.6.0`, version code `28`, package `org.textphone.launcher`, minimum Android version 7.0. The APK contains the native launcher and apps; it is not a flashable ROM.

Compilation results and artifact checksums accompany the release. The final build skips the test suite as requested. Phone gestures, camera output and live account synchronization still require handset verification.
