# Pocket Phone 0.5.18

Signed launcher update from commit `c8222a2efd6fb9e8c73207cdc4fc13694c8b9707` (version code 23).

1. If downloaded as a ZIP, extract it in Android Files.
2. Open `pocket-phone-0.5.18.apk` and allow installation from that file-opening app if Android asks.
3. Choose **Update**. Keep the existing Pocket installation; uninstalling deletes its local data.
4. Open Pocket. If Android asks for a default Home app, choose Pocket.

The package and signing certificate match 0.5.14. Existing local notes, tasks, tile assignments and app settings remain in the same app storage. No Android permissions were added.

This build includes the Home gesture handoff and deferred dashboard refresh, the latest home dashboard, readable tasks, task Drive sync, Movement/COROS, the native chat sidebar, provider settings, reply/caching controls, read-only Pocket access and pixel loading. Chat and account connections require your own configuration. Live APIs and the physical phone have not been tested here.

This is a launcher update for the current Nothing OS. The accompanying build report records the actual signing, tests and lint for this download.

Requires Android 7 or newer; compatible with the Nothing Phone (3a).
