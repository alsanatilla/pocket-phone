# Third-party components

Pocket's original code is MIT licensed. The native note preview uses Markwon 4.6.2 (`core`, `ext-tasklist`, `ext-strikethrough`) under Apache 2.0, copyright Dimitry Ivanov. Its commonmark-java parser and strikethrough extension use the BSD 2-clause license, copyright Atlassian Pty Ltd. AndroidX annotations use Apache 2.0. Markwon's image download, HTML and WebView plugins are not included.

The VT323 font (pixel titles and readings) and the IBM Plex Mono fonts (Regular, Medium and Italic, the reading face for all running text, copyright 2017 IBM Corp. with Reserved Font Name "Plex") are distributed under the SIL Open Font License 1.1. The phone bundles the three Plex Mono files in `app/src/main/assets/fonts` and the web app serves them from `public/fonts`. Full notices are in `third_party` and `app/src/main/assets/licenses`, and can be read through device settings → Open source licenses. Gradle's wrapper has its own Apache 2.0 distribution license. JUnit and Robolectric are build-time test dependencies; test code and fixture content are not shipped in the APK.

The Astro web/server project adds Astro 7.3.6, @astrojs/vercel 11.0.12, @libsql/client 0.18.0, Better Auth and its Drizzle adapter 1.7.7 under MIT, and Drizzle ORM 0.45.3 under Apache 2.0. Exact dependency versions and transitive packages are recorded in package-lock.json; installed packages include their upstream license files. The browser keeps its existing original modules and the fonts’ SIL Open Font License files in public/fonts.
